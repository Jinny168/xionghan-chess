## 2. 口径（与 `2026-10-31` 轮逐条一致）

1. **语料 16**：`desktop_complete` seed 700–703 × plies{4,8,12}=12；`web` 700–701 p8；`traditional` 700–701 p8。记 `id = sha1(position_key)[:16]` + `pieces/legal`。
2. **eval200**：4 profile × seed 700–709 × `build_position(...,12)` 取 `states[2,4,6,8,10]`；`red`/`black` 记 6 位小数。**重放必须 `game.move()`**（不得用 `rules.apply_unchecked`，后者在吃子线上会漂）；比对前须 `round(x,6)`。
3. **check20**：从 eval200 的 200 个局面枚举**一层合法后继**，筛「`black` 被将且 `red` 未被将」，按 `(profile 顺序, seed, 状态索引, 走法排序)` 取前 20。A 段 = seed 700–709；不足才启动 B 段（710–729）。每条记 `pass` 与 `src`。
4. **机动性 11 型**：各子单独置空盘 `(6,6)`、两王置红 `(12,6)` / 黑 `(0,0)`（不构成照面）；兵另测 `(5,6)`。另记初始局面红方首着各子着数（**按枚记，双枚子给 per 列表**）。
5. **开局快照**：初始局面每方 25 子的完整位置清单 + 各型数量。
6. **`t_d2`**：`hard` / `root_limit=18` / `randomness=0`；`AI_TIME_SCALE=2.5`→30s 预算，**d2 一完成立即 abort**；每局面 3 次。
7. **深参照 + 12s 选点**：corpus16 前 8（`desktop_complete` seed 700–703 × plies 4,8）+ 附加 `9a6b3275`（p12，`in_eight=false`）。深参照 `AI_TIME_SCALE=4`→48s ×1；12s 选点 ×3。

## 4. 已知局限

1. **`check20` 分布偏斜**：`desktop_classic 12 / desktop_complete 4 / web 4 / traditional 0`。按固定顺序取前 20 所致（A 段一次出满 20，未动用 B 段）；用途是覆盖 `in_check` 分支，不代表各档比例。
2. **`web` 档本轮出 4 条**——**前一版 README 写的"web 0 条"在本轮不成立**，尉/仕对调后 web 局面已能产生「`black` 被将且 `red` 未被将」的一层后继。历史轮次的"web 0 条"仅对那两版布局有效。
3. **开局有 2 个 0 着子：兵 (8,0) 与 (8,12)**。正前方被巡 (7,0)/(7,12) 堵死、未过河不能横走。与已修的尉不同：**巡首着 6 着，玩家可主动解开**，属"可迅速解锁"，本轮未改。
4. **样本量小**：语料 16 / 评估 200 / 将军 20 / `t_d2` 16 / 参照 8(+1)。用于**回归比对**，不用于统计推断。
5. **机动性表对"尉"这类受己方子阻挡的子天然失真**：尉空盘 24 着、初始首着 4 着；单看任一列都会误判。
6. **`traditional` 的两个 id16 与前两轮逐位相同**（该档无尉/仕对调影响），可作跨轮锚点；`desktop_complete` 与 `web` 因对调 id 全换。

## 5. 用途声明

**本目录是"将来任何评估/排序/规则改动"的对照组，不是"棋力合格线"。**

- 改动后用**同一批 `id16`、同一口径**重跑，逐位对比是否漂移；
- 它**不表达**"6/8 命中合格"或"t_d2 1.95s 达标"；
- **换规则、换布局或换语料后本目录整体作废**，严禁与其它版本数字相减。
