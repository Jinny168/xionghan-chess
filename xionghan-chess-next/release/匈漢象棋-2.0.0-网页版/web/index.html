      匈汉象棋使用帮助

      开始对局

      可选择人机对战、双人同机或网络对战。双人同机模式会按当前轮次自动允许红黑双方在同一设备操作。

      基本操作

      1. 点击或拖拽棋子完成走棋。
      2. 可在设置中分别控制选中高亮、合法落点与吃子提示。
      3. 暂停会同步停止三端计时，继续后恢复当前方计时。

      棋谱与复盘

      使用“文件”菜单保存、导出或读取 .xhgame 棋局。复盘窗口支持跳转、逐步查看、自动播放和本地棋谱库。

      规则提示

      • 射默认使用弱化星轨移动，加强选项可扩展其能力。
      • 斜向路径必须逐段通过夹逼检查，仕、士、相、象等同样适用。
      • 兵卒进入敌境前可快速行军，最大一步抵达敌境边缘。

      快捷键

      Ctrl+N 新建，Ctrl+O 读取，Ctrl+S 导出，Ctrl+Z 悔棋，Ctrl+R 复盘，F11 全屏。

      反馈支持

      GitHub Issues · 2741526119@qq.com

      棋子规则

      各棋子的详细规则、增强选项和夹逼判定可在“设置 → 规则与外观”中逐项查看和调整。

      斜向移动经过的每一段入口都必须通过夹逼检查；兵卒快速行军最多抵达敌境边缘。

      关于匈汉象棋

      版本 2.0.0

      匈汉象棋是一款采用 13 × 13 扩展棋盘、融合匈奴与东汉文化元素的中国象棋创新变体，在传统象棋核心博弈结构上加入特色棋子与可配置规则。

      当前版本

      • Windows、Web 与 Android 三端支持。
      • 共享 Python 规则、AI、联机协议和 .xhgame 棋谱格式。
      • 支持账号云同步、等量让子、观战、棋盘翻转、AI 分析和分级训练。
