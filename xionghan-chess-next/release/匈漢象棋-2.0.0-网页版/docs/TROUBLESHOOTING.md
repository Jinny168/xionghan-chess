# 常见问题

## `python` 没有输出或打开商店

使用 `py -3.11` 创建虚拟环境，后续直接调用 `.venv\Scripts\python.exe`。

## 桌面端缺少 PySide6

执行 `.\.venv\Scripts\python.exe -m pip install -e ".[desktop]"`。

## 浏览器无法连接 WebSocket

确认防火墙开放端口；反向代理必须转发 `Upgrade` 和 `Connection` 请求头。

## 两端棋盘版本不一致

服务器会拒绝旧 `revision` 的走棋并返回最新快照，不要绕过协议直接改棋盘。

## AI 高级档响应慢

高级档默认最多思考约 7 秒，可在界面降低难度。

## Docker 重启后房间消失

当前是单实例内存房间。需要重启持久化或多实例时应增加 Redis 存储适配器。

## 浏览器能打开但观战或联机不断重连

确认安装完整服务依赖：`py -m pip install -r requirements/server.txt`。若曾只安装基础 `uvicorn`，再执行 `py -m pip install websockets` 并重启服务。

## 让子对局提示双方数量不同

红黑两栏必须勾选相同数量。主帅固定登场，模式中不存在或已被规则开关关闭的棋子不能加入配置。点击“全部登场”可恢复正常对局。

## 黑先或随机先手时 AI 为什么先走

先手与玩家执子是两个独立设置。最终先手若不是玩家颜色，人机模式会由 AI 自动完成第一步；随机结果可在对局快照的 `setup.resolvedFirstMove` 查看。

## 登录后数据保存在哪里

默认保存在当前用户目录的 `.xionghan-chess/cloud.db`。可设置 `XIONGHAN_DATA_DIR` 修改目录；迁移服务器时备份该文件。

## 手机离线时为什么没有云同步和多人观战

账号、云棋谱、AI 分析和多人观战依赖 FastAPI 服务。Android 会在服务器恢复后自动切回完整在线工作台；离线页保留同机对局、主题、棋盘翻转、先手和内置训练。

## AI 分析为何与专业中国象棋引擎结论不同

匈汉完整规则和特色棋子没有现成第三方引擎。本版本使用项目内置 AI 的一致规则进行相对评分，适合发现明显失误和推荐候选，不声称等同于专业云算力分析。
