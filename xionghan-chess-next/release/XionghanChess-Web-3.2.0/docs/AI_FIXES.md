# AI Bug 修复清单

- AI 与玩家共用 `RulesEngine`，不再维护简化规则。
- 搜索使用局面副本，模拟走棋不会污染真实棋盘。
- 每层只遍历合法着法，阻止送将、越界、吃己方、吃楯和模式外棋子。
- 迭代加深保留上一层最佳结果，超时仍返回合法着法。
- 支持取消事件，重新开局或关闭窗口不会等待旧搜索。
- 桌面端 AI 思考锁阻止重复操作。
- 四档难度分别调整深度、时间预算和随机性。
- 升变、甲连线吃子和刺兑子进入统一状态转换。
- 捕获优先排序和 Alpha-Beta 剪枝减少无效搜索。
- 参考 Stockfish 搜索结构增加置换表、主变化优先、历史启发和 MVV-LVA 捕获排序。
- 叶节点使用静态吃子延伸搜索，降低刚好停在交换过程中的“地平线效应”。
- 无合法着法按失败局面计分，并优先选择更短的制胜路线。
- 无合法着法返回 `None`，由统一逻辑判断将死或困毙。
- `AI_TIME_SCALE` 可调整部署环境的统一思考时间倍率。
