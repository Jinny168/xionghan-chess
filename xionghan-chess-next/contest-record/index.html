「我想参加这个大赛，把咱们的匈汉象棋投稿，对标桌面版，优化我们的网页版，比赛要求网页版提交。」

02现状与三个关键判断

仓库里已有一个网页端 web/，但它只是 FastAPI 的前端壳子：走法判定、AI、计时全部依赖 Python 服务，无法作为一个链接直接分享。于是做了三个判断：

判断理由与代价
规则内核移植到 JS评审点开链接必须立刻能玩，静态托管没有冷启动与运维。代价是约 1,900 行移植， 必须证明规则与 Python 完全一致。
单文件构建发布平台的分享链接在首次访问时只授权 HTML 文档，CSS 与多个 JS 模块会拿到 403。 把样式、模块与 AI Worker 全部内联进一个 HTML，首屏请求从 12 个降到 1 个。
用 Python 生成黄金用例不靠人工抽查。让参考实现导出局面与合法着法全集，JS 端逐条比对， 差异即为缺陷。
