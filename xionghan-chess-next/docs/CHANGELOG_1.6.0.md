# 匈汉象棋 v1.6.0 更新日志（开发中）

## AI 进化

- 新增第五档 AI 难度 `master`（大师 / Master），通过新版共享规则引擎驱动纯 UCB1 MCTS。
- Web 与 Qt 桌面端难度选择器已展示大师档；服务端请求模型共享 `Difficulty` 枚举，可直接创建大师 AI 房间。
- 借鉴旧版 `desktop/ai/mcts/` 的树搜索设计，修正对手节点视角：根方节点最大化、对手节点最小化，并保留 UCB 探索项。
- 加入根节点战术先验：优先搜索安全吃子，并使用新版静态交换评估过滤明显亏损的吃子。
- 沿用 `AI_TIME_SCALE`、取消事件和 12 秒上限，不引入 NumPy、Redis、PyTorch 或旧棋盘编码。

## 工程与版本线

- 正式生产版本号提升至 `1.6.0`，Android 为 `versionCode=8` / `versionName=1.6.0`。
- 已移除误命名的 2.0.0 发布树；该构建不属于正式版本线。
- 新增 MCTS 接入、随机种子可复现、合法走法、双方视角 UCB 与第五难度档合同测试。

## 尚待完成

- MCTS 对高级 AI 的批量对弈强度与耗时基准。
- 规划中的跨引擎等价性、广播增量、安全加固、搜索裁剪、i18n 收尾及最终三端打包。

## 训练与验证基础设施

- 新增 `scripts/benchmark_ai.py`，支持颜色平衡的 master vs hard 批量对弈、逐步耗时统计、截断裁定标识与 JSON 报告。
- 完成 50 局快速筛查：大师平均单步约 0.417 秒、最大约 0.442 秒；全部为 2 ply 截断局，因此耗时链路通过但正式胜率验收未通过。
- 新增直接执行 APK 离线 `Rules` 源码的 Node 探针，Python 测试对四种规则配置及确定性局面比较合法走法集合和将军状态。
- 新增无 Redis 自博弈 JSONL 采样、稳定棋盘/动作编码及可选 NumPy policy/value 网络训练。
- 已完成真实最小闭环：2 条样本、1 epoch，模型成功保存为 NPZ。
