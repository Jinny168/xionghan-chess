## 1. 结论摘要

1. **最该先修的 3 件事**：① 将军态「红字压品牌绿底」——桌面 `1.13:1`、网页脉冲中点 `1.13:1`，等于把最关键的状态提示做成不可读（P0）；② 禁用态两端都失效——桌面**渲染像素与启用完全相同**，网页压到 `2.61:1`，用户点了没反应且不知道为什么（P1）；③ 桌面最小窗口 `560px` 高与布局需求 `740px` 冲突，棋谱列表被压到 **53px（≈2.8 行）**（P1）。
2. 两端**都没有设计令牌**：网页 46 行 CSS 里有 **84 个 hex + 22 个 rgba**，桌面 5 个 UI 文件里有 **45 个 hex**（含 5 套主题）。颜色、间距、字号全部是"就地取值"，这才是上面三条能同时发生的根因。
3. 字号没有阶梯：网页用了 **12 种字号**（11/12/13/14/15/16/18/19/20/23/24/25），桌面是 10pt 基准 + 15px 横幅 + 棋盘内动态字号，`15/19/23` 不在任何比例体系里。
4. 间距没有栅格：网页 `gap` 有 **57 处声明 / 16 种取值**、`padding` 有 **69 处声明**；桌面 `padding:7px` 与 `min-height:35px`、菜单栏 34px、状态栏 30px、横幅 39px —— 没有一项落在 8 的倍数上。
5. 状态矩阵残缺：桌面 QSS **只有 `:hover`**；网页 `:hover` 4 / `:active` 1 / `:disabled` 1 / `:focus` **0**。
6. 图标没有体系：网页用 Unicode 字符当图标（`⇄ ▣ ↥ ◀ ↕ ↶ Ⅱ ↻ ×`），桌面干脆没有图标 —— 两端都谈不上"一套图标"。
7. 好消息：**棋盘绘制本身**（几何、线宽、主题跟随）比 UI 外壳规范得多（`board_geometry.py` 是纯函数 + 有单测），问题集中在"棋盘以外的壳"。
8. 建议按 §4 的顺序修：前 5 项合计约 **3 人时**，能覆盖全部 P0 与一半 P1；令牌化与前 5 项不要合成一次大改。

## 3. 统一规范提案

> 目标：两端共用一套**数值**。主题色相可变，**刻度与语义不变**。

### 3.1 间距刻度

- 基数 **4**；允许值只有 `4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 分配：
  | 场景 | 值 |
  |---|---|
  | 图标与文字间距 | 8 |
  | 控件内 padding（紧凑/常规） | 8 / 12 |
  | 同组控件间距 | 8 |
  | 按钮组间距 | 12 |
  | 分组（fieldset/卡片内） | 16 |
  | 区块（卡片之间） | 24 |
  | 页面/窗口边距 | 32（≥1280）/ 16（<760） |
  | 控件高度（桌面/触摸） | 40 / 44 |
- 现有值映射：`5→4`、`7→8`、`9→8`、`15→16`、`18→16 或 24`、`22→24`、`35→40`、菜单栏 34→32、状态栏 30→32、横幅 39→40。

### 3.2 字号阶梯（px，桌面按 96dpi 折算）

| token | 字号 | 行高 | 用途 | 替代现有 |
|---|---|---|---|---|
| `caption` | 12 | 16 (1.33) | 次要说明、`kbd`、时间戳 | 11, 12 |
| `body-s` | 14 | 21 (1.5) | 列表、表格、菜单 | 13, 14 |
| `body` | 16 | 24 (1.5) | 正文、按钮、输入 | 15, 16, 13.33(10pt) |
| `title` | 20 | 26 (1.3) | 面板标题、对话框标题 | 18, 19, 20 |
| `headline` | 24 | 32 (1.33) | 页面标题、品牌 | 23, 24, 25 |
| `display` | 32 | 40 | 战绩数字、棋盘内"将军" | （新增） |

- 字重只有 **400 / 500 / 700**；700 仅用于品牌名与将军态。
- 棋盘内字号继续用 `cell` 比例计算（`cw*.38` 等），但需 clamp 到上表的档位，不要产生 17.3px 这类值。

### 3.3 颜色语义（浅 / 暗）

| token | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| `ink` | `#211b17` | `#f2ede6` | 正文 |
| `ink-2` | `#5c5048` | `#c6beb1` | 次要文字（替代 `#6f6254`/`#756555`/`#776653`/`#675748`/`#746353`） |
| `ink-3` | `#8b8175` | `#9b9186` | 禁用/占位 |
| `line` | `#d5bea0` | `#4a4238` | 分隔线 |
| `line-strong` | `#9d8768` | `#75624b` | 控件边框（替代 8 种） |
| `surface` | `#fffaf0` | `#282b2d` | 卡片底 |
| `surface-2` | `#f1dfb7` | `#34383a` | hover / 次级底 |
| `brand` | `#315c48` | `#4d8069` | 主色（ribbon/banner 底） |
| `danger` | `#b3261e` | `#f2b8b5` | 危险文字（**不得压 brand 底**） |
| `danger-surface` | `#7f1d1d` | `#93000a` | 危险底色（配白字 8.2:1） |
| `success` | `#2e6b4f` | `#7fc9a4` | 成功 |
| `warning` | `#8a5a00` | `#f0b429` | 警告 |
| `focus` | `#1a73e8` | `#8ab4f8` | 焦点环 |

- **硬约束**：`danger` 只能压在 `surface` / `surface-2` / `danger-surface` 上；压在 `brand` 上一律改用 `danger-surface + 白字`。
- 5 套主题只换 `brand` 与 `surface` 的色相，`ink/line/danger/success/warning/focus` 全部复用上表（暗色主题换右列）。

### 3.4 状态矩阵（每个交互组件 8 态）

| 态 | 视觉（浅色） | 备注 |
|---|---|---|
| default | `surface` + `1px line-strong` | |
| hover | `surface-2`（M3 state layer 8%） | 桌面已有 |
| focus | `2px focus` 外环 + 1px 内描边 | **两端都缺** |
| pressed | `surface-2` 加深（12%）+ `translateY(1px)` | 网页有、桌面缺 |
| disabled | `ink-3` 文字 + `surface` 底 + `line` 边框 | 与 hover 必须有肉眼差异 |
| selected | `brand` 8% 底 + `brand` 文字 | 列表/选项卡 |
| loading | 14px 旋转弧（700ms/linear）+ 文字 60% | 桌面缺 |
| error | `2px danger-surface` 边框 + `danger` 文字 | AI 异常、网络断开 |

可点最小：触摸 **44×44**，鼠标 **36×36**（桌面按钮高统一 40）。

### 3.5 图标规范

- 网格 **24×24**，描边 **1.5px**，圆角端点，**统一线性**（不混填充）。
- 尺寸：行内 16 / 按钮 20 / 工具栏 24；与文字间距 8。
- 颜色 `currentColor`，随文字自动继承状态色。
- 首批 8 个：`undo / pause / restart / resign / draw / replay / save / flip`；**禁止再用 Unicode 字符当图标**（`⇄ ▣ ↥ ◀ ↕ ↶ Ⅱ ↻ ×` 需全部替换）。

## 4. 修复顺序（按 影响面 ÷ 成本 排，不按严重度机械排）

| 顺序 | 动作 | 覆盖问题 | 成本 | 影响用户面 | 前置/风险 |
|---|---|---|---|---|---|
| 1 | 将军态配色：banner 改 `danger-surface + 白字`，网页脉冲只改 scale | U-15, U-16 | 0.5 人时 | 每局至少 1 次，攻杀局极频繁 | 需同时定 `danger-surface` 一个值 |
| 2 | 禁用态：桌面补 `:disabled` 规则，网页改"文字不透明、底降档" | U-18, U-17 | 0.5 人时 | 每局第一步的「悔棋」、终局的「暂停」 | 与 §3.3 的 `ink-3` 一起定 |
| 3 | 暗色次要文字：7 处 `#6f6254` → `ink-2` | U-13（含 U-19 的一半） | 0.5 人时 | 暗色主题用户的全部说明文字 | 需先有 token 常量（可先放 `theme.py`） |
| 4 | 最小窗口：`setMinimumSize(760,740)` 或右栏可折叠 + 棋谱区最小高 | U-06 | 1 人时 | 小屏/分屏用户 | 可能触发既有 UI 截图基线更新 |
| 5 | 英文按钮宽度：最小宽 120 或按语言定宽 | U-25 | 0.5 人时 | 英文用户 | 需过一次 en 截图 |
| 6 | 颜色令牌化（CSS 变量 + `theme.py` 常量），收敛 84+45 → ~24 | U-19, U-21, U-04, U-22 | 3 人日 | 全体（不改观感，只改真源） | **前 5 项的根**；建议前 5 项先落地，再统一收口 |
| 7 | 字阶 + 间距令牌（含 px/pt 统一） | U-10, U-11, U-12, U-07 | 2 人日 | 全体 | 会改变所有界面像素，需重跑视觉基线 |
| 8 | 图标集 + 状态矩阵 + 焦点样式 | U-03, U-23, U-24, U-26, U-02 | 4 人日 | 全体 | 需美术出 8 个图标；桌面/网页各接一次 |

> 前 5 项合计约 **3 人时**，覆盖 1 个 P0 + 4 个 P1；第 6 项是"不再复发"的关键，但不应与前 5 项合成一次大改。
