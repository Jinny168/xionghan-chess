# 更新日志 2.1.0

> 版本唯一来源：`src/xionghan_chess/__init__.py` 的 `__version__`。
> 规则语义零改动，`RULE_VERSION` 仍为 **3**。

## 本轮做了什么（按批次）

### 训练内容（批次 A）
- **章节化闯关**：题库 35 → 48 条，按「揭竿 / 垓下 / 定鼎 / 破釜 / 逐鹿」五章排版，未归章题目单独成组。
- **守题补足 + 连对挑战**：答错不锁题、连对给额外星级，章节进度按 `scored` 计。
- 星轨提示与文字提示**分两条线**：星轨按「是否在答题」屏蔽，文字提示按 `scored` 分流（章节闯关可用且计星）。

### 视觉与信息层级（批次 B / C / D）
- **上一步标记方框化**（公网门面）：由与棋子同心的金色圆盘改为格内圆角方框，内缩 5%、圆角 16%、盘线色；不再遮挡棋子、随主题走。
- **特色棋子徽记**：尉＝双短斜杠、射＝四角星＋细环、檑＝三条短横、巡＝空心小方；桌面字形/位图/缺图回退**三路径同款**，颜色非唯一载体（色盲可辨）。
- **三端参数收口**：盘半径统一 0.39、字号 1.15r、投影偏移 0.10r、可吃点半径 0.42 格、落子动画三端 320ms。
- **反馈分层**：toast 分成功 / 信息 / 警示 / 错误四级，两棵树同事件同文案。
- **侧栏减负**：低频设置折进「详情」「更多操作」，首屏常驻信息减少；功能与快捷键零删减。
- **`prefers-reduced-motion` 降级**（webapp / web）：系统「减少动态」时落子改淡入、关闭将军脉冲；桌面无系统级入口，已记 `KNOWN_ISSUES`。
- **「无背景」不再被静默改写**：用户选什么就存什么。
- **高对比棋子组**（默认关闭，可在设置切换）：traditional 同图换色，棋子墨色在六组主题实测全部 ≥4.5:1。

### 玩法与工具
- **双 AI 观战**（桌面）：双方 AI 自动对弈，1200 / 600 / 250 ms 三档调速、暂停继续、单步；观战期人手落子被拦，退出逐项还原历史/回合/子力，棋谱不被演示局污染。
- **入门陪练档**：单层评分带 censoring 软取样（150cp 内、吃子过 SEE、候选池不含第 1 名），概率唯一来源 `CONFIGS.beginner.randomness = 0.18`，可实例级关闭；20 局固定种子实测触发率 13.30%。
- **复盘报告初版**（桌面）：聚合失误数 / 关键手 / 局面曲线 + 归纳式结论；**非权威口径**（不出现「你应该……」），离线本地、无网络无遥测、不改棋谱格式。

### 工程与门禁
- **三端视觉对齐清单**：14 项参数矩阵落成数据（`docs/visual_alignment_ledger.json`）+ 漂移守卫 `tests/test_visual_alignment_triad.py`；任何一端改参数都必须显式更新清单，目前 **drift 0**。
- **证据哈希守卫**：不同目检点截图必须哈希互异、且与模板逐条对应，杜绝「一张图挂两个名字」。
- **守卫不再静默跳过**：`git` 缺失时 `_has_commit()` 不再伪装成「产物依赖跳过」，改为硬失败或带明确原因的跳过。
- **发布链**：`scripts/release.py --all-local` 一条命令完成打包 + 装到 `D:\匈汉象棋`（稳定名 `匈漢象棋.exe` + 版本副本）。

## 已知限制
- 桌面端无系统级「减少动态」入口（PySide6 6.12.0 `QStyleHints` 无该 API）。
- 深底 / ink 主题下可走点、可吃点仍低于 3:1（已文档化，未新增默认主题色值）。
- 真人目检 M-1…M-7 的证据已备齐，结论栏待人工填写。
- PGN/FEN 互通、多计时档位、外部引擎接入：按计划仍不做（格式与状态机红线）。
