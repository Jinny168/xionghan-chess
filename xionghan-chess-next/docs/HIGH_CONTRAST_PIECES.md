# 高对比棋子组（E1）

> 开关：`highContrastPieces`（webapp / web 旧树偏好键）、`high_contrast_pieces`（桌面配置键），
> **默认 `false`**。开启后只对棋子墨色做程序化派生，**不覆盖用户已选的棋子风格 profile 与主题**。
> 三端同一套派生公式（桌面 `contrast.py`、`webapp/js/ui/board.js`、`web/js/app.js` 逐行对应）。

## 1. 派生口径（零新增色值）

- 公式：WCAG 2.x 相对亮度 `L = 0.2126R + 0.7152G + 0.0722B`，对比比 `(L1+0.05)/(L2+0.05)`。
- 方向：浅底（盘底相对亮度 > 0.179）把墨色向**黑**混；深底向**白**混。
- 步长：`0.05`，迭代到首个达标比例即停；混到极值仍不达标则保留极值色并记录实测比值，不偷加色板条目。
- 判据：棋子描边 / 文字属文本，目标 **4.5:1**；可走点圆盘、可吃点环/盘属非文本图形，目标 **3:1**（WCAG 1.4.11）。
- 白名单 `benchmarks/color_allowlist.txt`：本批**条目数不变（139 条）**，无新增字面量；派生输出色由既有令牌运行时混色算出，源码只出现令牌名或 mix 调用。
- **作用域（硬约束）**：所有派生、提不透明、半径放大只在 `highContrastPieces` 开启的高对比组内生效；默认主题的提示点像素输出与基线逐值相同，棋子墨色派生逻辑不动。

## 2. 实测对比表（before / after）

数据由 `scripts/measure_contrast_high_contrast.py` 从三端源码/令牌取色计算；下表为该脚本输出的整理，
复跑：

```
python scripts/measure_contrast_high_contrast.py          # 表格 + 末行 JSON
python scripts/measure_contrast_high_contrast.py --json   # 仅 JSON
```

- **before** = 默认主题：既有半透明提示令牌与盘底合成后的等效对比（现状）。
- **after** = 高对比组：既有提示令牌派生到图形 3:1、提为不透明；可走点半径放大一档到 0.16 格。

| 端 | 主题 | 可走点 before→after | 可吃环 before→after | 可吃盘 before→after |
|---|---|---|---|---|
| desktop | classic | 2.18 → 4.73 ✓ | 3.03 → 3.41 ✓ | 1.75 → 5.29 ✓ |
| desktop | dark | 3.38 → 6.54 ✓ | 2.05 → 3.15 ✓ | 1.09 → 3.03 ✓ |
| webapp | classic | 3.35 → 5.10 ✓ | 3.76 → 4.75 ✓ | — |
| webapp | ink | 1.55 → 3.11 ✓ | 1.68 → 3.04 ✓ | — |
| web | classic | 3.43 → 6.30 ✓ | 4.09 → 4.54 ✓ | — |
| web | dark | 1.54 → 3.05 ✓ | 2.26 → 3.08 ✓ | — |

棋子墨色（文本 4.5:1）三端六组主题派生后全部达标，详见脚本 JSON 的 `piece_red` / `piece_black` 项。

- **图形（提示点）after：三端全部 ≥ 3:1**；before 不达标的 8 组（desktop/classic 可走点/盘、desktop/dark 环/盘、webapp/ink 点/环、web/dark 点/环）派生后均达标，派生比值不低于 before 现状。

## 3. 派生与尺寸补偿选择

- **颜色派生**：提示点沿用既有令牌（可走点绿、可吃环/盘红），高对比组内按盘底方向混色到图形 3:1；
  深底上的令牌向白提亮、浅底向黑压暗，步长 0.05 首个达标即停。**不新增色板条目**，派生最终值只出现在
  脚本输出 / 本文件 / 门禁测试中。
- **提不透明**：before 缺口的主因是半透明 alpha 与盘底合成后对比被拉低；高对比组内提示点提为不透明，
  消除合成损耗。默认主题的 alpha 档位原样保留。
- **尺寸补偿**：高对比组内可走点半径由 0.13 放大到 **0.16 格**（授权上限 0.18 格；桌面深色主题默认 0.15 不变）；
  可吃环/盘半径保持 0.42，面积充足，对比问题靠颜色派生解决。三端同常量 `LEGAL_DOT_RATIO_HC = 0.16`。
- **判据适用理由**：可走点圆盘、可吃点环/盘属非文本图形，按 WCAG 1.4.11 的 **3:1** 判据评估，不套用正文 4.5:1。
- **默认主题不变**：上述派生、提透明度、放大仅在开关开启时生效；关闭开关后提示点回到既有半透明令牌与默认半径，
  已选主题 / 棋子风格 profile 不被覆盖。

## 4. 不变量

- `RULE_VERSION` 不升；规则 / 存档 / PGN 零改动。
- 不做 canvas 像素基线；两条线判据（星轨按题态屏蔽 / 文字提示按 scored 分流）不合并。
- 开关持久化在三端各自偏好/配置；切换不改已选 profile / 主题。
