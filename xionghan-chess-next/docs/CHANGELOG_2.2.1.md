# 更新日志 2.2.1

> 版本唯一来源：`src/xionghan_chess/__init__.py` 的 `__version__`。这是一次补丁版本，规则语义零改动，`RULE_VERSION` 仍为 **3** —— 走子与胜负判定一行未动，改的是稳定性、复盘呈现与多端文案。

## 稳定性：几个「什么都不发生」的老毛病已修

- **终局弹窗不再因为战绩写盘失败而消失**。以前磁盘异常时会出现「对局结束了，界面却毫无反应」，而且后台还在不停重试、反复报错。现在弹窗照常出现，胜负结果照常显示。
- **自动存档失败会重试一次**，而不是一次写不进去就放弃。存档时的异常都会被捕获，不会再因为磁盘问题打断对局。
- **题解里「对手应着无法落子」会被明确告知**：本题已中止，可以回到训练列表重新选题。以前这句提示与实际状态正好相反，而且之后的每一手都会跟着误判——现在中止就是中止，不会再把一手已经走不下去的题继续判下去。

## 复盘：不再给你精确分值，改看档位与走势

- **去掉「评分下降 120」「损失 500」这类精确数字与胜率百分比**。这些数字来自有限的搜索深度，精确到个位并不可靠，反而容易误导。现在只给出**档位**（如好 / 一般 / 失误）和**相对走势**，并明确标注这是「浅层参考」。
- **分析手数由 40 手提高到 120 手**。中后盘的失误不再因为超出旧上限而被略过；如果一局真的长到被截断，会明确提示「只分析了前 120 手」，不会让人误以为整局都看过了。

## Web / 手机端

- **英文界面不再夹中文**：AI 复盘弹窗的标题、加载提示、逐手档位标签，以及「浅层参考」这条说明，都会跟着界面语言切换。
- **换棋谱时旧的分析结果不再贴到新棋谱上**：换棋谱、读档、导入棋谱都会先作废上一局的分析，逐手点评不会张冠李戴。
- **本地存储写入失败会提示一次**：进度存不进去时会告诉你一声，不再像以前那样悄悄丢失。

## 设置

- **手改坏的配置数值不再导致启动崩溃**：比如把音量之类写成了非数字，程序会把它收敛回可用值，正常进入游戏，而不是一启动就闪退。
- **使用完整规则档的老用户会收到一次「轻量模式」推荐提示**：只在首次启动时提示一次，**不会自动改动你的规则档位**，是否切换完全由你决定。

## 不改的东西

- 走子、吃子、将军、将死、困毙、入宫判定的规则语义一律未动（`RULE_VERSION` 仍为 3）。
- AI 强度标定、主题与配色基准未动。
- 题库局面与判题逻辑未动。
