# 匈汉象棋 v1.8.2 更新日志

> 本版本是一次**界面与文案的校准**：让「棋子与规则」窗口演示的东西与这枚子真正能做的动作一致，
> 让所有规则开关统一成「勾选 = 增强」，并修掉关于页里停留在 1.7.0 的版本号。
> 规则判定本身没有改动。

## 棋子与规则窗口：演示随棋子裁剪

- **原来所有棋子共用同一套四个预设**（自由 / 夹逼 / 三连 / 照面），夹逼演示的主角还硬编码成「射」。
  于是车、炮、马、兵、巡都会看到一个它们根本不存在的"斜线夹逼"演示。
- 现在按棋型裁剪：
  - 夹逼：只给有斜线段的棋型（仕/士、相/象、尉/卫、射/䠶、檑/礌，以及规则允许斜走的汉/汗）
  - 三连吃子：只给兵，且开关打开时才出现
  - 将帅照面：只给汉/汗
- 夹逼演示改用**当前选中的那枚子**当主角；「不可出宫」的士改摆九宫内，否则一格都走不了。
- 顺带修掉一个潜在缺陷：选中将/帅时，演示盘会摆出两个红王。

## 开关极性：统一为「勾选 = 这枚子更强」

三个开关的存储字段沿用历史的负向写法（`True` 表示"少了一种能力"），界面显示一律取反：

| 存储字段 | 界面标签 | 勾选含义 |
|---|---|---|
| `king_lose_diagonal_outside_palace` | 出九宫后保留斜走 | 勾 = 保留斜走 |
| `horse_blocked_by_leg` | 马不受别腿限制（同国际象棋） | 勾 = 不受限制 |
| `horse_straight_three_move_only` | 直走三格可以吃子 | 勾 = 可以吃 |

- **只改呈现不改存储**：老配置、存档、AI 参数、跨引擎对拍全部照旧。
- 网页通过 `/api/profiles` 的 `negatedOptions` 拿到同一份名单，三端行为一致。
- 上游关掉时下游开关**置灰并给出提示**，消除"勾着却不生效"的歧义
  （典型：经典模式下「直走三格可吃子」勾着，但「允许直走三格」已关）。

## 布局：两栏竖排

- 原来三栏「棋子清单 | 演示盘 | 详情」，演示与详情并排抢宽度。
- 改为两栏：左＝棋子清单；右＝自上而下「美术风格 → 走法演示 → 规则正文 / 开关」。
- 三段叠起来必然超过一屏，右栏整体可滚动；详情区不再自带滚动条（避免嵌套滚轮跳动）。
- 演示盘最小高度 240 → 200，窗口维持 900×640，1366×768 的屏幕放得下。

## 版本与文案

- **关于页的版本号不再写死**：`ABOUT.md` 里的「版本：1.7.0」改为 `{{VERSION}}` 占位符，
  运行时注入 `__version__`；API 的 `FastAPI(version=...)` 同样改为单一来源。
- 帮助里的规则提示按模式重写（射是否加强、兵的特技在哪些模式开启、夹逼适用于哪些棋子）；
  马的长描述改为正向表述。
