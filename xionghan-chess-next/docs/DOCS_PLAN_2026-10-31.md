## 5. 风险：被引用的文件（**一律不许删/移，只能改**）

| 文件 | 引用点 | 后果 |
|---|---|---|
| `src/xionghan_chess/desktop/resources/docs/PIECE_RULES.md` | `desktop/app.py:492`、`desktop/ui/piece_atlas.py:642,668`、`tests/test_desktop_theme_resources.py:43-45,68` | 游戏内「规则」窗口 + 图谱中文页**运行时读取**；测试断言存在。删/移 = 运行时报错 + 测试红 |
| 同上 `ABOUT.md` / `HELP.md` | `desktop/app.py:504`、`tests/test_desktop_theme_resources.py:43-44` | 「关于」窗口运行时读取 |
| `docs/PIECE_RULES.md` | 与上面那份**逐字节相同**（`diff -q` 通过） | 两份副本，**改一处必须同步另一处**；建议后续加一条测试或构建期拷贝，避免再次分叉 |
| `docs/DESKTOP_ITERATION_PLAN_1.7.0.md` | `desktop/app.py:601`、`desktop/ui/__init__.py:4`（代码注释） | 注释失效但不报错，**可移动，只需同步注释里的路径** |
| `docs/AUDIT_DESKTOP_1.7.0.md` | `desktop/ui/board_widget.py:7`（注释） | 同上 |

**另外两条风险**
1. `docs/` 与 `src/.../resources/docs/` 是**两份物理副本**，`pyproject.toml:33` 只把后者打进包；前者改动**不会**进入安装包 —— 这是最容易漏的一环。
2. 归并会改动 `PIECE_RULES.md` 的路径（若按提案移到 `docs/rules/`），而 `piece_atlas.py` 用 `theme.read_docs("PIECE_RULES.md")` 读的是**资源目录**，不受影响；但若有人把 `docs/PIECE_RULES.md` 也移走，需同步 README 与注释里的路径。
