# 架构与功能说明

- `core/model.py` 是唯一棋盘、棋子、走棋、棋谱和计时数据模型。
- `core/profiles.py` 只描述模式差异，不包含分散的走棋逻辑。
- `core/rules.py` 是唯一合法走棋、将军、将死、困毙和特殊吃子实现。
- `core/game.py` 是唯一状态转换入口，负责历史、悔棋、复活、升变和结果结算。
- `core/ai.py` 只调用规则引擎生成合法着法。
- 联网时 FastAPI 服务端持有权威 `Game`，客户端只提交走棋意图。

| 档案 | 棋盘 | 默认棋子 |
| --- | --- | --- |
| `desktop_complete` | 13x13 | 11 类 / 全场 50 子（每方 25） |
| `desktop_classic` | 13x13 | 11 类（含尉）/ 48 子（每方 24） |
| `web`（精简模式） | 13x13 | 10 类（含尉、无巡）/ 44 子（每方 22） |
| `traditional` | 9x10 | 传统中国象棋棋子 |

每个房间有递增的 `revision`。客户端消息携带当前版本，版本不一致时服务器拒绝走棋并返回
最新完整快照。断线重连使用随机令牌恢复座位。

## 功能

- 四套规则档案及每局自定义规则开关。
- 原版桌面的逐棋种登场开关与独立加强能力开关，汉/汗固定登场。
- 射/䠶有效星轨弱化模式与可脱离星轨、最多三格的强化模式。
- 完整合法走棋、禁止送将、将军、将死、困毙和入宫胜利。
- 三次重复、无进展和双方协议和棋。
- 棋谱、权威快照复盘、协商悔棋、重新开局和认输。
- 倒计时、超时判负、断线重连和断线超时判负。
- 兵卒进入敌境前快速行军、复活和使用阵亡棋子的升变。
- 点击与拖拽、选中高亮、可行点、吃子目标和将军提示。
- 13×13 原版“长城 / 阴山”中央分界、短交叉点位和兵炮初始位角标。
- 六档 AI（beginner / easy / medium / hard / expert / master）、先后手切换和 AI 思考锁。
- 自建房间、Web/桌面跨端联机和版本校验。
- 统一联机聊天协议与“挑衅”等快捷短语，不干扰棋局状态版本。
- PySide6 配置持久化、PyInstaller 和 Docker 部署。
