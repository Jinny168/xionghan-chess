```
匈汉象棋是传统中国象棋的变体：13×13 棋盘，中央不是河，而是一道「长城—阴山」分界；双方各十四种棋子，其中射、檑、甲、刺、楯、巡六种为本作独有——射沿对角星轨行走，檑只能近身吃子，甲三子连线可夹杀，刺与敌子同归于尽，楯不可被吃且庇护相邻棋子，巡只在两条巡界线上横移。

网页版把完整的 Python 规则内核逐行移植到 JavaScript：走法判定、将军、将死、困毙、入宫胜利、兵卒升变与复活、三次重复，全部在浏览器本地完成，不依赖服务器，打开链接即可开局。面向想随手下一盘、又对传统象棋规则感到熟悉的玩家，也面向愿意研究新棋种规则的爱好者。

功能包括四套规则档案（完整 / 经典 / 精简 / 传统 9×10）、四档 AI 棋力、双人同机、悔棋、提示、认输、逐手复盘、棋谱导入导出，以及一个可交互的「棋子图谱」：点亮任意棋子，就能看到它在这张棋盘上的全部可达点，规则一眼看懂。

为保证移植可信，我用 Python 参考实现导出了 372 个局面、848 次走子、23,741 条合法着法，与 JS 端逐条比对，结果完全一致。
```
