# 匈汉象棋 v1.5.0 更新日志

发布日期：2026-08-13

## 新增

- 内置 9 张头像素材，统一裁切为 256 x 256 WebP。
- Web 账号页支持选择内置头像，并保留外部 HTTP/HTTPS 头像 URL。
- 桌面端账号菜单支持修改显示名称与头像；联机玩家状态区显示内置头像。
- Android 离线大厅支持头像选择与本地持久化，棋局页显示所选头像。
- 账号与房间协议支持 `builtin:avatar-XX` 标识，旧头像 URL 和无头像账号继续兼容。

## 发布收尾修复

- 按审计 0 节方案 A，将生产源码、Web 缓存参数、Docker、桌面与 Android 统一为 1.5.0。
- 修复 Android 离线端未执行 `no_progress_draw_plies` 的规则分歧；连续 120 ply 无吃子且无兵卒走动时，与 Python Core 一致判为无进展和棋。
- 补充三次重复和无进展和棋的 Android 离线中英文终局文案。

## 延续功能

- AI 场景化自动挑衅与独立开关。
- 三端轨迹动画、将军脉冲提示和默认首字符头像回退。
- MCTS 纯推理模块保留为实验能力，未接入默认 AI 难度档位。

## 兼容性

- SQLite 账号数据库自动迁移，无需手工执行脚本。
- Android `ApplicationVersion` 升至 7，可覆盖安装 v1.4.0。
