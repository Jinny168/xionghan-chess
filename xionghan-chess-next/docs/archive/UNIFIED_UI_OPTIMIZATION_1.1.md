# 匈汉象棋三端统一 UI 与功能优化方案（1.1.0）

## 一、统一公共功能清单

三端以 Python `Game`、`RulesEngine`、`RuleProfile`、WebSocket `Envelope` 和 `.xhgame` 作为唯一规则、状态、协议与棋谱基线。Android 联网界面直接使用 Web 客户端，桌面端通过相同核心与协议实现原生界面；禁止客户端自行修改胜负与合法走法语义。

| 模块 | 统一能力 | 验收口径 |
| --- | --- | --- |
| 对局 | 人机、双人同机、联网房间、悔棋、提和、认输、暂停/继续、每方计时、读秒提醒 | 三端使用相同模式名、指令和结果原因；暂停状态由服务端权威同步并冻结计时 |
| 棋谱 | 自动保存、本地棋谱库、导入、导出、继续对局、逐步复盘、自动演示 | 统一 `.xhgame` formatVersion 1；导入时校验规则档案、步数与快照一致性 |
| 设置 | 规则档案、AI 四档难度、棋盘主题、背景、三种棋子样式、声音、音量、走棋动画、选中高亮、合法落点、吃子提示 | 设置项采用相同中文名称与默认值；视觉设置本机持久化，规则设置新局生效 |
| 辅助 | 使用帮助、棋子规则、历史记录、胜负统计、累计走子 | Web/Android 使用对话框，桌面使用同层级原生对话框；结果仅记录一次 |
| 交互 | 点击与拖拽、选中高亮、落点提示、吃子提示、吃子反馈、结果弹窗、重连、防误触 | Canvas/棋盘命中测试不得改变渲染缓冲；pointer cancel、状态版本和服务端合法性三层防护 |

## 二、统一 UI 规范

### 2.1 设计令牌

- 主色：汉红 `#9d2525`；状态绿 `#315c48`；强调金 `#c9933b`。
- 纸色背景：`#f1dfb7`；面板：`#fffaf0`；正文：`#211b17`；分隔线：`#59422e`。
- 主界面不使用紫色作为主色；紫晶仅作为用户主动选择的棋盘皮肤。
- 桌面字号基准 14 px / 10 pt，移动端不低于 12 px；棋子文字统一使用楷体回退链。
- 按钮最小高度 35 px，移动触控按钮不低于 40 px；主操作为实心汉红，次操作为纸色描边。

### 2.2 信息架构

- 顶级菜单固定为：文件、对局、复盘、视图、设置、帮助。
- 棋盘居中作为第一视觉层；玩家与计时、模式设置、棋谱/聊天位于两侧，窄屏按棋盘、操作、设置、记录顺序纵向排列。
- 通用对局操作固定为：悔棋、暂停/继续、重开、认输、提和、复盘、保存、导出、复活兵卒。
- 设置分为：界面外观、声音、走棋辅助、通用裁定、棋子与规则。

### 2.3 反馈时序

- 点击反馈立即发生；棋子选中立即高亮；服务端确认后播放走棋/吃子反馈。
- Web 动画 360 ms；复盘自动播放 850–900 ms/步；Toast 约 2.2 s。
- 暂停遮罩、结果弹窗和提和/悔棋确认均阻止棋盘继续输入。
- 联网断开显示“正在重连”，凭证保留 90 s；恢复后以服务端 revision 覆盖本地选中状态。

### 2.4 自适应规则

- 桌面端最小窗口 760 × 560，可隐藏侧栏；棋盘按可用区域等比缩放。
- Web 在 1180、1050、760、420 px 设置断点；移动端操作按钮为 3/4 列网格，无水平滚动。
- Android 使用沉浸式全屏，状态栏和导航栏隐藏；系统栏仅允许边缘滑动临时显示。
- Canvas 像素尺寸使用 DPR（上限 2），仅在容器尺寸变化时重建缓冲。

## 三、Android 专项修复清单

1. 修复棋盘空白根因：命中测试原先调用带副作用的 `geometry()`，每次 pointer up 都重设 `canvas.width/height` 并清空位图；现已拆分为纯几何读取与 `syncCanvasSize()`。
2. 增加 `ResizeObserver`、窗口 resize、visibilitychange、Activity `OnResume`、`OnWindowFocusChanged` 和页面完成回调六类重绘触发。
3. WebView 开启硬件图层、DOM Storage、JavaScript 和媒体播放，禁用页面缩放控件，避免双指缩放造成误触。
4. Android 11+ 使用 WindowInsets 隐藏状态栏/导航栏；旧版使用 immersive sticky 标志；窗口重新聚焦时再次应用。
5. 离线同机页补齐暂停计时、时限、读秒提醒、主题、棋子样式、合法落点、吃子提示、音效和音量。
6. 文件导入使用系统文件选择器，导出使用 SAF `ACTION_CREATE_DOCUMENT`，不申请宽泛存储权限。
7. 服务器健康检查失败自动进入离线同机，连续失败才从联网页面降级，避免瞬时网络抖动。

## 四、桌面端优化项

1. 顶级菜单调整为与 Web 相同的六组结构，联网入口并入“对局”。
2. 新增暂停/继续按钮与 `Ctrl+P`，直接调用公共核心冻结计时；联网时发送统一 `pause` 指令。
3. 棋盘最小尺寸由 540 降为 420，主窗口最小尺寸由 920 × 680 降为 760 × 560。
4. 新增传统书法、现代简约、卡通风格三种原生棋子渲染；补齐紫晶棋盘皮肤。
5. 新增动画、选中高亮、合法落点、吃子提示和读秒阈值设置。
6. 新增本地棋谱库，可按修改时间浏览、复盘、继续，并保留打开存储目录入口。
7. 计时进入阈值后使用统一红色警示；暂停时棋盘显示统一遮罩。

## 五、Web 端优化项

1. 新增暂停/继续菜单和棋盘下方操作按钮，消费服务端权威暂停状态。
2. 新增 5/10/20/30/60 分钟时限与 10/30/60 秒读秒提醒。
3. 设置弹窗补齐动画、选中高亮、合法落点、吃子提示和自动保存开关。
4. 对局结束自动进入本地棋谱库并累计红胜、黑胜、和棋、走子数；同一结果键只记录一次。
5. 重连计时器去重，pointercancel 清理拖拽，ResizeObserver 保障窗口与移动浏览器地址栏变化后的重绘。
6. 760 px 以下操作区改为网格；420 px 以下进一步压缩标题和玩家卡，确保无横向溢出。
