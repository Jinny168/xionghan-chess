# 棋子行棋规则

本文档描述 `core/rules.py` 的统一规则。坐标从左上角开始，红方通常向行号减小的方向前进，黑方向行号增大的方向前进。所有棋子都遵守以下公共限制：不能原地移动，不能落在己方棋子上；除规则明确允许外，不能越过路径上的棋子；开启“禁止送将”时，走完后己方汉/汗不能处于被将状态。

斜向路径的**夹逼判定**只适用于斜走的六种棋子：**汉/汗（九宫内斜走）、仕/士、相/象、
尉/卫、射/䠶、檑/礌**。判定口径：移动方向垂直的两侧同时有棋子时该段无效；
跳子类（射/檑）要求起点与每个中间路径点都通过夹逼检查；尉按普通斜走子处理。

## 汉 / 汗（KING）

- 每次横、竖移动一格。
- 在本方九宫内，是否允许斜走一格由“九宫内斜走”控制。
- 出九宫由“允许出九宫”控制；关闭时只能落在本方九宫内。
- 出九宫后是否失去斜走能力由“出九宫后失去斜走”控制。
- 进入敌方九宫是否立即获胜由“进入敌方九宫获胜”控制。
- 两个汉/汗不能在同一直线无遮挡地照面：**同列或同行**、且两者之间没有任何棋子即禁止
  （照面**计入被将**：`in_check` 为真，等于让自己处于被将的着法非法）。

## 车（ROOK）

- 沿横线或竖线任意距离移动。
- 目标为空时只能直线移动；目标为敌子时可以吃子。
- 起点和目标之间不能有棋子。

## 马（HORSE）

- 普通走法为“日”字：横二竖一或横一竖二。
- “马腿”位置有棋子时不能走。
- 开启“马直走三格”后，还可以横向或竖向直走三格，三格路径必须为空。

## 相 / 象（ELEPHANT）

- 普通走法为斜向两格，即“田”字。
- 中间格称为象眼，象眼有棋子时不能走。
- “允许过长城阴山”关闭时，不能落入敌方区域；开启时可以过界。
- 进入敌方区域后，若同时开启“敌境横竖两格”，可以横向或竖向移动两格，中间格必须为空。

## 仕 / 士（ADVISOR）

- 在本方九宫内只能斜走一格。
- “允许出九宫”关闭时，不能落在九宫外；已在九宫外的异常状态只能斜走返回九宫。
- 出九宫后保留斜走能力。
- 开启“出九宫后可直走”后，在九宫外还可以横、竖走一格。

## 炮（CANNON）

- 不吃子时沿横线或竖线移动，路径必须完全为空。
- 吃子时沿横线或竖线移动，起点和目标之间必须恰好隔一个棋子。
- 不能吃己方棋子。

## 兵 / 卒（PAWN）

- 在本方区域只能向前走一格。
- 开启“进入敌境前快速行军”时，可沿前进方向移动 `n` 格，`n >= 1`，最大值为当前位置
  到敌境边界的距离。移动超过一格时不能吃子，且所有中间点和目标点都必须为空。
- 快速行军到达敌境边界后即停止，不能一次越过边界；已经进入敌方地盘后不再拥有该能力。
- **过阴山后**可以横走一格。13 行棋盘上阴山为 row 6（`rows // 2`），阴山行**本身不算**
  进入敌境：红兵 `row ≤ 5`、黑卒 `row ≥ 7` 才能横走。该口径与「快速行军最远落行 5」、
  「象/相正交两格要求 `row < 6`」三处一致。
- 到达敌方底线后，可按开关允许后退一格，或获得横、竖四向一格移动能力。
- 开启「三连吃子」时：移动兵后，若该兵所在直线上与己方另一子共同围住敌方一子（三者紧挨、两我一敌、顺序不限），则吃该敌子；移动兵未参与的线不结算。
- 开启复活时，可消耗一回合在空的出生点复活己方已阵亡兵卒。
- 开启升变时，到达敌方底线**必须升变**：只能升变为己方阵亡池里、且当前模式允许登场的
  非兵卒、非汉/汗棋子，并从阵亡池**取走**该枚（池内该类型数量减一）。
  池中没有任何可升变类型时，该兵**不升变**、以兵的身份停在底线（实测：此时走到
  底线是合法着法，落子后仍是兵）。

## 尉 / 卫（GUARD）

- **斜向任意距离**移动与吃子，路径必须无子（与相/象、仕/士的斜走同规则）。
- **不能走直线**：任何横/竖方向都不是合法着法。
- 斜线沿途每一段入口都要通过**夹逼**检查（同其它斜走子）。
- 落点为空则移动，落点为敌子则吃；被任何棋子挡住即停，不能越过。

## 射 / 䠶（ARCHER）

- 只能沿斜线移动，不能走到己方棋子上。
- 有效星点以 3 格为间距，并按交错棋盘格分布。以星点索引计算时，仅保留行列索引和为
  偶数的点，因此 `(0,0)`、`(3,3)` 属于相邻有效星点，而 `(0,3)` 不是有效星点。
- 弱化模式（默认）只能沿有效星轨移动。起点和终点必须位于同一条相邻星点线段内；
  `(0,0) -> (3,3)` 合法，`(0,0) -> (4,4)` 非法。位于线段中间时可在两端点之间任意移动。
- 强化模式可脱离星轨自由斜走最多三格；吃子时起点必须位于有效星点。
- 两种模式都不能越过棋子；目标有棋子时只能是敌子。
- 起点和每个中间路径点都进行斜向夹逼检查。移动方向垂直的两侧同时有棋子时，移动无效。

## 檑 / 礌（THUNDER）

- 可以沿横、竖或斜线移动。
- 目标为空时路径必须为空；斜线移动还要通过夹逼检查。
- 斜向吃子同样必须通过夹逼检查。
- 吃子只能攻击相邻八方向内的敌子。
- 目标敌子必须是孤立棋子，四个正交相邻位置不能有同色保护子。

## 刺 / 伺（ASSASSIN）— 已移除

**已于 2026-10-31 移除（软删，可回滚）。** 原为「前进一格 + 斜向任意距离吃」。
枚举 `PieceType.ASSASSIN` 与 `rules.py::_assassin` 分支保留，把 `assassin_appear` 打开即可回滚。

## 甲 / 胄（ARMOR）— 已移除

**已于 2026-10-31 移除（软删，可回滚）。** 原为「沿直线移动，三子连线夹吃」。

## 楯 / 碷（SHIELD）— 已移除

**已于 2026-10-31 移除（软删，可回滚）。** 原为「护住同阵营四正邻子」。

## 巡 / 廵（PATROL）

- 横线与竖线**同规则**（不再局限于行 5 / 行 7）。
- 必须移动**偶数格**，路径不能有棋子。
- 目标为空时可移动；**距离两格**时允许落在敌子位置进行吃子，其他距离不能吃子。

## 规则开关与模式

棋子是否登场由规则档案和每局的棋子登场开关共同决定。档案中不存在的棋种不会因开关被重新添加；汉/汗始终保留。所有开关会进入对局快照，桌面、Web、AI 和 WebSocket 服务使用同一份配置。
