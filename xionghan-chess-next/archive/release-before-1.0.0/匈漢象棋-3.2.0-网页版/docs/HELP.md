# 匈汉象棋使用帮助

桌面、Web 和 Android 的完整用户指南随应用内“帮助 -> 使用帮助”提供。主要功能包括人机对战、双人同机、网络房间、跨端 `.xhgame` 棋谱、独立复盘和规则配置。

## 快速操作

- 点击棋子查看合法落点和吃子提示，再点击目标位置移动。
- `Ctrl+N` 新建对局，`Ctrl+O` 读取棋局，`Ctrl+S` 导出棋局。
- `Ctrl+Z` 悔棋，`Ctrl+R` 复盘，`F11` 全屏。
- 射默认使用弱化星轨规则；斜向路径需逐段通过夹逼检查。
- 兵卒进入敌境前可快速行军，最大一步抵达敌境边缘。
