## 13:30 运维发现：后台 python 会被降频

- 后台 Bash 起的 `python.exe` 初始 `PriorityClass=Normal`，实测只跑到 **25% 单核**
  （60 s 墙钟只涨 15 s CPU），1 局 52 手要 11 分钟才落盘。
- 用 `Get-Process -Id <pid> | % { $_.PriorityClass='AboveNormal' }` 后立刻回到 **99% 单核**。
- 以后长跑基准先在启动后设一次优先级；否则 ETA 会虚高 4 倍。
- 另：venv 的 `python.exe` 是启动器，会派生子进程，`Get-Process python` 会看到两个 PID，
  CPU 只在子进程上累加。
