# 匈汉象棋使用帮助

匈汉象棋是在中国象棋基础上发展出的 13 x 13 扩展棋类游戏，融合匈奴与东汉文化元素，并加入射、檑、尉、甲、刺、楯、巡等特色棋子。

## 开始对局

- **人机对战**：选择规则档案、AI 难度和执子颜色后开始。
- **双人同机对弈**：两名玩家在同一设备轮流操作，也可用于自己复盘推演。
- **网络对战**：创建房间后分享房间号，另一名玩家输入房间号加入。
- **规则档案**：精简、经典、完整和传统象棋提供不同棋盘、棋子与默认能力。

## 基本操作

1. 点击己方棋子进行选择。
2. 棋盘会显示合法落点；可吃目标会显示吃子提示。
3. 点击高亮落点完成移动，再次点击已选棋子可保持选择。
4. 同机模式中，系统会按当前轮次自动允许红方或黑方操作。

## 对局功能

- **悔棋**：同机模式撤销一步；人机模式通常撤销双方最近一轮。
- **认输 / 提和**：结束当前棋局；联机模式会向对手发送相应请求。
- **复盘**：打开独立复盘窗口，可跳转、逐步查看或自动播放棋谱。
- **保存 / 读取**：使用 `.xhgame` 文件跨桌面、Web 和 Android 保存及恢复棋局。
- **本地棋谱库**：Web 和 Android 可在复盘窗口保存棋谱，并继续、导出或删除。
- **全屏**：按 `F11` 切换全屏。

## 规则提示

- 汉/汗除将死取胜外，还可按规则选项进入敌方九宫获胜。
- 射/䠶默认使用弱化星轨移动；开启加强选项后可获得更自由的斜向移动能力。
- 斜向移动经过的路径入口必须逐段通过夹逼检查，仕/士、相/象等适用斜向路径的棋子同样遵守夹逼裁定。
- 兵卒在进入敌境前可快速行军，最大一步抵达敌境边缘；进入敌境后的移动按当前规则档案处理。
- 更完整的棋子能力与选项请查看“帮助 -> 棋子规则”或“设置 -> 规则与外观”。

## 常见问题

### 为什么不能移动某个棋子？

确认是否轮到该颜色、目标是否为合法落点、移动路径是否被棋子或夹逼点阻挡，以及该能力是否在当前规则档案中开启。

### 如何保存和继续棋局？

桌面端使用“文件 -> 导出棋局 / 导入棋局”。Web 和 Android 可使用“文件 -> 保存到本机、导出棋局、读取棋局”，复盘窗口中的本地棋谱也可直接继续。

### Android 无法连接服务怎么办？

模拟器访问开发机通常使用 `http://10.0.2.2:8000/`；真机需填写同一局域网内可访问的服务器地址，并确认防火墙允许对应端口。

### AI 强度如何调整？

在人机模式中选择入门、初级、中级或高级。更高难度会增加搜索深度和计算时间。
