# 关于匈汉象棋

**版本：1.4.0**

匈汉象棋是一款融合中国象棋策略传统、匈奴与东汉历史文化元素的创新棋类游戏。项目通过 13 x 13 扩展棋盘、特色棋子和可配置规则，在保留传统象棋核心博弈结构的同时提供更多战术变化。

## 当前版本

- PySide6 原生 Windows 桌面客户端。
- FastAPI + WebSocket 网页客户端与权威对局服务。
- Android WebView 客户端，支持系统文件读取和棋谱另存为。
- 三端共享 Python 规则、AI、联机协议和 `.xhgame` 棋谱格式。
- 支持人机、双人同机、网络对战、复盘、聊天和棋谱管理。

## 项目愿景

项目希望以现代软件方式延续象棋的策略文化，在传统规则之上探索新的棋盘空间、棋子关系与历史表达，并为学习、娱乐和棋类 AI 研究提供可持续扩展的实现。
