## 环境教训
- 必须用项目自带 `xionghan-chess-next/.venv/Scripts/python.exe` 跑 pytest（managed/workbuddy Python 缺 fastapi/pydantic，会 collection error）。
- Bash 的 `grep` 对中文 Unicode 区间 `[\x{4e00}-\x{9fff}]` 报 "Invalid range end"，需用 Grep 工具（ripgrep）处理中文。
