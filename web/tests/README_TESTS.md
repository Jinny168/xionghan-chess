## ❌ 失败的测试 (5个) 及说明

### 1. 将/帅/汉/汗 - 汉在九宫内直走应合法 ❌

**测试代码**:
```javascript
assert(GameRules.isValidKingMove(pieces, 'red', 10, 6, 9, 6) === true, 
       '汉在九宫内直走应合法');
```

**失败原因**: ⚠️ **这是预期行为**

根据当前规则实现，将/帅/汉/汗在九宫内可以8方向移动（包括直走和斜走）。但测试中使用的起始位置`(10,6)`已经在九宫内，目标位置`(9,6)`也在九宫内，应该是合法的。

**建议修复**: 检查`isValidKingMove`函数中的九宫判断逻辑，或者调整测试用例的坐标。

assert(GameRules.isValidKingMove(pieces3, 'red', 4, 6, 3, 6) === true,

### 3. 炮 - 炮移动到空位无阻挡应合法 ❌

**测试代码**:
```javascript
assert(GameRules.isValidPaoMove(pieces, 2, 1, 2, 8) === true, 
       '炮移动到空位无阻挡应合法');
```

**失败原因**: ⚠️ **测试场景问题**

炮从`(2,1)`移动到`(2,8)`，路径上有一个己方兵在`(2,3)`作为炮架。但炮移动到**空位**时，路径上**不应该有任何棋子**。

**正确理解**:
- 炮**吃子**时：必须有且仅有一个炮架
- 炮**移动**时：路径上不能有任何棋子

**修复方案**: 修改测试用例，移除路径上的棋子：
```javascript
const pieces = [new Pao('red', 2, 1)];
assert(GameRules.isValidPaoMove(pieces, 2, 1, 2, 8) === true, '...');
```

### 4. 兵/卒 - 卒过河后左右移动应合法 ❌

**测试代码**:
```javascript
assert(GameRules.isValidPawnMove(pieces, 'black', 4, 6, 4, 5) === true, 
       '卒过河后左右移动应合法');
```

**失败原因**: ⚠️ **规则实现问题**

黑方卒在`(4,6)`，已经越过长城（黑方长城在第7行，卒在4行说明已深入敌境）。根据规则，过河后可以左右移动。

**可能的问题**:
1. `hasCrossedGreatWall`判断可能有误
2. 对于黑方，越过长城应该是`row <= 5`而不是`row >= 7`

**检查代码**:
```javascript
// game-rules.js 第543-544行
const hasCrossedGreatWall = (color === 'red' && fromRow <= 5) ||
                            (color === 'black' && fromRow >= 7);
```

**修复**: 黑方卒在`(4,6)`，`fromRow=4`，不满足`fromRow >= 7`，所以判定为未过河。应该改为：
```javascript
const hasCrossedGreatWall = (color === 'red' && fromRow <= 5) ||
                            (color === 'black' && fromRow <= 5); // 黑方向下走，小数是敌方
```

### 5. 将帅照面 - 移动后不会导致将帅照面应合法 ❌

**测试代码**:
```javascript
assert(GameRules.wouldCauseKingsFacing(pieces, 'red', 10, 6, 9, 6) === false, 
       '移动后不会导致将帅照面应合法');
```

**失败原因**: ⚠️ **函数返回值理解错误**

`wouldCauseKingsFacing`返回`true`表示**会导致照面**（应该禁止），返回`false`表示**不会导致照面**（允许移动）。

测试中断言`=== false`期望"不会照面"，但实际返回了`true`，说明移动后确实会导致照面。

**分析**:
- 红方汉在`(10,6)`，黑方汗在`(2,6)`
- 红方汉移动到`(9,6)`
- 两者在同一列（col=6）
- 中间没有其他棋子
- **结果**: 将帅照面，返回`true`（会照面）

**修复**: 这个测试的预期值应该改为`true`，或者添加一个棋子在中间：
```javascript
// 方案1: 修改预期
assert(GameRules.wouldCauseKingsFacing(pieces, 'red', 10, 6, 9, 6) === true, 
       '移动后会导致将帅照面');

// 方案2: 添加中间棋子
pieces.push(new Pawn('red', 6, 6));
assert(GameRules.wouldCauseKingsFacing(pieces, 'red', 10, 6, 9, 6) === false, 
       '中间有棋子不会照面');
```
