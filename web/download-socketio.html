🔧 Socket.IO 客户端库下载工具

说明：由于网络代理问题，CDN 可能无法直接访问。本工具提供多种方案获取 Socket.IO 库文件。

方案一：自动下载（推荐）

点击下方按钮尝试从多个 CDN 源下载 Socket.IO 库文件到本地。

方案二：手动下载（如果自动下载失败）

  1. 访问以下任意链接下载 socket.io.min.js：
    • Cloudflare CDN
    • unpkg CDN
    • jsDelivr CDN
  2. 将下载的文件保存为 socket.io.min.js
  3. 将文件复制到项目目录：web/js/network/
  4. 刷新游戏页面即可

方案三：使用 npm 安装（适合开发者）

  1. 打开终端，进入项目目录
  2. 运行命令：npm install socket.io-client@4.7.5
  3. 从 node_modules/socket.io-client/dist/socket.io.min.js 复制文件到 web/js/network/
