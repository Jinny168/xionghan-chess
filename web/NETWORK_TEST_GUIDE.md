# 网络对战本地测试指南

## 📋 测试环境要求

- **操作系统**: Windows/macOS/Linux
- **浏览器**: Chrome 90+ / Firefox 88+ / Edge 90+（推荐Chrome）
- **Python**: 3.7+
- **需要打开**: 2个或更多浏览器窗口/标签页

## 🚀 快速开始

### 1. 启动服务器

```bash
cd C:\Users\27415\PycharmProjects\xionghan-chess\web\server
python app.py
```

服务器将在 `http://localhost:5000` 启动。

### 2. 创建房间（第一个窗口）

1. 打开浏览器，访问 `http://localhost:5000`
2. 点击 **"创建房间"** 按钮
3. 系统会自动生成一个8位房间号（例如：`A3F7B2C1`）
4. 房间号会自动复制到剪贴板
5. **保持此窗口打开**

### 3. 加入房间（第二个窗口）

1. **打开新的浏览器窗口**（建议使用无痕模式或不同浏览器）
2. 访问 `http://localhost:5000`
3. 点击 **"加入房间"** 按钮
4. 在输入框中粘贴或输入房间号
5. 点击 **"加入"** 按钮
6. 等待连接成功

### 4. 开始游戏

- 当两个玩家都进入房间后，游戏会自动开始
- 第一个创建房间的玩家执**红棋**（先手）
- 第二个加入的玩家执**黑棋**（后手）

## 🔧 常见问题

### Q1: 为什么无法连接？

**可能原因：**
- 服务器未启动
- 端口被占用
- 防火墙阻止

**解决方法：**
```bash
# 检查服务器是否运行
netstat -ano | findstr :5000

# 如果端口被占用，杀掉进程
taskkill /F /PID <进程ID>

# 重新启动服务器
python app.py
```

### Q2: 如何在同一浏览器中测试？

**方法1：使用无痕模式**
- Chrome: `Ctrl + Shift + N`
- Firefox: `Ctrl + Shift + P`
- Edge: `Ctrl + Shift + N`

**方法2：使用不同浏览器**
- 窗口1: Chrome
- 窗口2: Firefox

**方法3：使用不同用户配置文件**
```bash
# Chrome多用户
chrome.exe --profile-directory="Profile 1"
chrome.exe --profile-directory="Profile 2"
```

### Q3: 房间号在哪里查看？

- 创建房间后，会弹出对话框显示房间号
- 房间号已自动复制到剪贴板
- 也可以从URL中查看：`http://localhost:5000/game.html?mode=online&room=XXXXX`

### Q4: 如何调试网络连接？

打开浏览器的开发者工具（F12），查看Console标签：

**正常连接日志：**
```
✅ Socket.IO连接成功, ID: xxxxx
🚪 加入房间: A3F7B2C1
✅ 成功加入房间，阵营: red
⏳ 等待对手连接...
👥 对手已连接，准备开始游戏
🎮 游戏开始！您执红
```

**错误日志示例：**
```
❌ Socket.IO连接错误: Connection refused
❌ 无法连接到服务器，请检查网络连接
```

### Q5: 游戏过程中断线怎么办？

- Socket.IO会自动重连（最多10次）
- 重连间隔：1秒、2秒、4秒、8秒...（指数退避）
- 如果重连失败，需要重新加入房间

## 🐛 调试技巧

### 1. 查看Socket.IO连接状态

在浏览器控制台输入：
```javascript
// 检查连接状态
console.log(game.network.isConnected());

// 查看房间信息
console.log(game.network.getRoomId());
console.log(game.network.getPlayerCamp());
```

### 2. 手动发送测试消息

```javascript
// 发送聊天消息
game.network.sendChat('测试消息');

// 发送悔棋请求
game.network.sendUndoRequest();
```

### 3. 监控网络事件

```javascript
// 监听所有Socket.IO事件
game.network.socket.onAny((event, ...args) => {
    console.log('Event:', event, 'Data:', args);
});
```

## 💡 优化建议

### 性能优化
- 使用WebSocket传输而非HTTP polling
- 减少不必要的日志输出（生产环境）
- 启用gzip压缩

### 用户体验
- 添加连接进度条
- 显示对手在线状态
- 添加重连提示
- 优化错误提示信息

### 安全性
- 添加房间密码功能
- 实现移动验证（服务端）
- 防止作弊（时间戳验证）
- 限制操作频率
